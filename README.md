# 🌱BaroFarm
Generative AI-powered local food e-commerce platform developed for the 2025 Hanium Dream Up Team Project.

## Overview
BaroFarm is a prototype of a generative AI-powered local food e-commerce platform that utilizes the OpenAI API and prompt-based LLM applications to simplify product registration and enhance the shopping experience. Key AI features include automated product description generation, AI-assisted product page creation, and a customer support chatbot.

## Key Features
* AI Product Description Generation  
  - Generates product descriptions using the OpenAI API and prompt engineering.
* AI Product Page Generation  
  - Automatically creates product page layouts based on generated content.
* AI Chatbot  
  - Provides shopping assistance using prompt-based LLM interactions.
* Personalized Recommendation  
  - Recommends products based on user preferences and purchase history
